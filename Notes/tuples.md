# Tuples
this is a fixed length array where each element has a particular type we often  use them when working with a pair of values for example let's say for each user we want to represent two values an id and name 
this is a typed array with a pre-defined length and types for each index
tuples allow each element in the array to be of a known type of value

for example: 
```typescript 
let user: [number, string] =[1, 'Munya']```
